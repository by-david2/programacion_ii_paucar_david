# Programación II

Repositorio correspondiente a la asignatura **Programación II**, donde se desarrollarán diferentes proyectos, ejercicios y prácticas relacionados con el desarrollo de software.

## 📚 Contenido

Durante el curso se trabajará principalmente con las siguientes tecnologías:

### 🐍 Python

**Python** es un lenguaje de programación de alto nivel, interpretado y de propósito general. Se caracteriza por tener una sintaxis sencilla y fácil de leer.

En este repositorio se utilizará Python para:

- Aprender y reforzar conceptos de programación.
- Desarrollar ejercicios y proyectos.
- Trabajar con estructuras de datos.
- Utilizar funciones, clases y programación orientada a objetos.
- Crear aplicaciones y automatizaciones.

### 🌐 Django

**Django** es un framework web desarrollado en Python que permite crear aplicaciones web de manera estructurada y eficiente.

Se utilizará para aprender conceptos como:

- Desarrollo de aplicaciones web.
- Modelos y bases de datos.
- Vistas y plantillas.
- URLs y rutas.
- Formularios.
- Autenticación de usuarios.
- Arquitectura MVT (Model-View-Template).

### 🏢 Odoo

**Odoo** es una plataforma de gestión empresarial (ERP) desarrollada principalmente con Python. Permite crear y administrar diferentes módulos para las necesidades de una empresa.

Se trabajará con conceptos como:

- Módulos de Odoo.
- Modelos y campos.
- Vistas.
- Menús y acciones.
- Seguridad y permisos.
- Desarrollo de módulos personalizados.
- Integración con bases de datos.
